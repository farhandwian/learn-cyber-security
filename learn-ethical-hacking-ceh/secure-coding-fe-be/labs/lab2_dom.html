Lab 2: DOM sinks

Open this file in your browser (it is a local page; the only "attack" is a harmless alert box). Paste one payload at a time into the box, then click each button and compare.

  • HTML payload: <img src=x onerror="alert('xss ran')">
  • URL payload: javascript:alert('xss ran') (then click the link that appears)

What you should see

  • innerHTML: the alert pops (the "text" became live HTML). textContent: the payload is shown literally.
  • raw href: clicking the link runs the alert. allowlist: the link goes nowhere (#).

Now imagine input.value is a comment from another user stored in your database. That is stored XSS.
